Midnight Helper — Project History (Phases)
Reference log for future updates.

--------------------------------------------------------------------------------

Phase 1–34: De basis van de addon: Core systeem, SavedVariables, de UI-shell met sidebar en de initiële tab-logica.

Phase 35–79: Opbouw van de Delves-rooster data, valuta-tracking (Keys/Undercoins) en de eerste versie van de Great Vault-weergave.

Phase 80: Ontwerp van de verbeterde Profession-lijst layout met sectie-headers en zebra-striping voor betere leesbaarheid.

Phase 81: UI Opschoning: Verwijderen van dubbele titels en het herstellen van overlappende knoppen onderin het scherm.

Phase 82: Visuele "Makeover" van de Delves-tab om deze gelijk te trekken met de gouden stijl van de Professions-tab.

Phase 83: Herstel van de Bountiful-detectie logica om compatibiliteit met WoW patch 12.0.5 te garanderen.

Phase 84: Implementatie van debug-prints en een geforceerde data-refresh om verbindingsproblemen met de Blizzard-server te analyseren.

Phase 85: Stabilisatie-fase: Terugdraaien van experimentele iconen naar de betrouwbare Blizzard Atlas-iconen (portaal/kaars) in de Delves-tab.

Phase 86: Shared Smart Navigation: De "Travel Assistant" (portalen en Hearthstone-hulp) uit de Delves-module is nu ook beschikbaar voor alle items in de Profession-tab.

Phase 87: Toevoegen van de "About" info-knop onderaan de sidebar met vermelding van de auteurs: Inchy & Gemma & Cursor.

Phase 88: Addons Framework & Platynator Module Base. Created a modular sub-tab system within the main UI and established the Addons/ folder structure for isolated modules.

Phase 89: Visual Platynator Guide & Image Gallery. Implemented scrollable gallery for Platynator module, added Wago link EditBox, and fixed nil value errors in UI logic.

Phase 92: Interactive Gallery for Platynator. Implemented a clickable thumbnail system with a main preview area to fix UI overflow issues and improve readability.

Phase 100: Platynator Module — Major Milestone. Finalized the Platynator integration with a pixel-perfect, interactive UI. Features include a side-by-side dual-link system (Wago & Custom Profile), a streamlined button layout for one-click copying, and a fully functional image gallery. Removed all debug code and optimized vertical spacing for a professional look.

Phase 101: Custom Profile Implementation. Replaced the placeholder string in PlatynatorData.lua with the official 'Inchy v1.0' Platynator profile. Verified that the long-string formatting is intact and the character limits are disabled to ensure all style and profile data loads correctly.

Phase 102: Spikey's Guardian Guide (sidebar-tab `guide`). Nederlandse tips met spell-iconen, sectie Gear & Stats, nature/druid-tint, scroll-layout; routing via `UI.lua` / `ns.panels.guide`. Implementatie: `Guide.lua` + `GuideGuardian.lua` (sinds Phase 107).

Phase 103: Guide UI-verfijning: compactere tip-iconen (24px) en vaste rijhoogtes; level-keuzemenu op `UIDropDownMenuTemplate` i.p.v. EasyMenu (nil-crash vermeden).

Phase 104: Per-level talent-roadmap in de addon: `GUARDIAN_BY_LEVEL` / Icy Veins-mijlpalen en level-dropdown (preview 1–90) naast de tips.

Phase 105: Talent-sectie vereenvoudigd: intern per-level talentadvies en level-dropdown verwijderd. In plaats daarvan vaste Icy Veins Guardian leveling-URL in een `EditBox` (Ctrl+A / Ctrl+C → plakken in browser). Bovenbalk alleen titel, geen override meer.

Phase 106: Spell-tooltips op de tip-iconen: per tip een `Button`-hitbox over het icoon; bij hover of klik toont `GameTooltip` de Blizzard-spell (`SetSpellByID`, fallback `spell:`-hyperlink), bv. Mark of the Wild, Moonfire, Bear Form.

Phase 107: Guardian-gids opgesplitst: `Addons/GuideGuardian.lua` bevat alle Guardian-data en UI; `Addons/Guide.lua` is alleen de `EnsureMainUI`-hook die `ns.SetupGuardianGuideModule()` aanroept. `.toc`: GuideGuardian vóór Guide.

Phase 108: Restoration Druid guide (`Addons/GuideResto.lua`): zelfde layout als Guardian, eigen Icy Veins restoration-leveling-URL, 10 Resto-tips met Engelse spellnamen, titel "Restoration Guide — Spikys", blauw/groene tint. `Guide.lua` roept `SetupRestoGuideModule` aan, `ns._mhUpdateGuideSpecVisibility` wisselt Guardian/Resto op Druid spec 4; geünificeerde `ns:_mhGuideRefresh`. Guardian-frames hernoemd (`MidnightHelperGuardianGuideFrame`, …) om botsingen te vermijden.

Phase 109: Sidebar-tab `guide` hernoemd naar "Leveling Guides" (`UI.lua`). Bovenbalktitels in `GuideGuardian.lua` / `GuideResto.lua`: `UnitName("player")` aan het begin van elke `Setup*GuideModule` (na de built-guard), titels `Guardian Guide — <naam>` en `Restoration Guide — <naam>`.

Phase 110: Universal Guide Machine — `Addons/GuideData.lua` met `ns.GuideData[classToken][specIdx]`; één `SetupUniversalGuideModule()` in `Guide.lua` die tips, Icy Veins-EditBox en stats uit data vult. `UnitClass` tweede return + `GetSpecialization()`; zonder passende entry: Guardian-Druid-data als fallback (niet-Druid of spec buiten 1–4; zie Phase 111), anders placeholder NL. Bij spec-/vensterwissel opnieuw opgebouwd. `GuideGuardian.lua` / `GuideResto.lua` verwijderd. English: data-driven, scalable for more specs.

Phase 111: Completed Druid specialization data. Added Balance (`[1]`) and Feral (`[2]`) to `GuideData.lua` with tips, Icy Veins links, stats, themes. All four Druid specs work in the Universal Guide; `Guide.lua` fallback aangepast (alleen niet-Druid of spec buiten 1–4 → Guardian).

Phase 112: Death Knight guide data in `GuideData.lua`: `ns.GuideData["DEATHKNIGHT"]` for Blood (`[1]`), Frost (`[2]`), and Unholy (`[3]`) — Nederlandse tips met spell-iconen, Icy Veins leveling-URLs, stats, en per-spec themes (rood / ijs-blauw / onheil-groen).

Phase 113: Integrated Consumables section (Food/Flask/Potion) into the Universal Guide system. Updated Druid and Death Knight data. Added full Demon Hunter guide data.

Phase 114: Added Evoker guide data (Devastation, Preservation, Augmentation). All tips include Blizzard spell tooltips and spec-specific consumables.

Phase 115: UI & Logic Fix. Implemented a clearing mechanism to prevent overlapping text. Fixed class data lookup to prevent incorrect Druid fallback on non-Druid classes.

Phase 116: Low-level character support. Added fallback logic for characters below level 10 (Spec 0) to display the first available specialization guide instead of a placeholder. Note: This logic was refined in Phase 117 to provide better feedback instead of a forced fallback.

Phase 117: Smart Onboarding. Replaced generic placeholder with level-specific instructions. Characters below level 10 see a leveling goal, and characters at level 10+ without a spec see an overview of their available options.

Phase 118: Implemented full Hunter guide data (Beast Mastery, Marksmanship, Survival). Added class-specific tips, stats, and consumables.

Phase 119: UI Ghosting fix & DH Devourer Update. Added live refresh for level-ups and spec changes. Reordered onboarding logic to list all available specs for characters at level 10+. Added the third Demon Hunter spec (Devourer).

Spec lock uses `1..GetNumSpecializations()` so invalid indices (e.g. pre-choice state) show the spec picker instead of a false “guide missing” message. Active guide header shows role: `Title (Role) — player`.

Phase 132: Universal Guide — scroll viewport & populate stability. Dropped `UIPanelScrollFrameTemplate` for the guide body (template layers could hide the scroll child on 12.x while data still built). Added `ScheduleGuidePopulate()` with short retries until `guideRoot:IsVisible()` and the scroll frame has sane height; `PopulateUniversalGuideContent()` returns early when the guide panel is not visible. `UI.lua` refreshes the guide after selecting the guide tab and after showing the main window; `ClearGuideUI()` no longer strips arbitrary `GetRegions()` on the scroll child (use `lastGuideCenterFs` + `gearHost` instead). Call `UpdateScrollChildRect()` after content rebuilds where appropriate.
