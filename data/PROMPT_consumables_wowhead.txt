You are helping build a World of Warcraft addon data file for **Midnight Helper**.

## Your task

Produce **one valid JSON file** with recommended **PvE consumables per class and specialization** for the current retail patch.

**Primary source:** Wowhead (official item pages and class guides on wowhead.com).  
**Secondary cross-check only:** Icy Veins consumables sections — do not copy their text verbatim.

## Output rules (strict)

1. Output **only JSON** — no markdown fences, no commentary before or after.
2. Every item must include a numeric **item ID** verified on Wowhead (`https://www.wowhead.com/item=ID`).
3. Item **names** must match the **enUS** in-game name from Wowhead.
4. Include a **wowheadUrl** per item (`https://www.wowhead.com/item=ID`).
5. If a category does not apply to a spec (e.g. **Death Knight has no weapon oil** — Runeforging), set `"omitWeaponOil": true` and omit the `weaponOil` object OR set it to `null`.
6. **Do not invent item IDs.** If you cannot verify an ID, omit that entry and add a string in `"warnings": ["..."]` at spec level.
7. Use **English** for `noteEn`; optional `noteNl` (Dutch) one short sentence per category max.
8. Cover **all 39 retail specs** (no Devourer DH):

## JSON shape

Top level:

```json
{
  "meta": {
    "gameVersion": "<e.g. 12.0.5>",
    "contentPhase": "<e.g. Midnight Season 1>",
    "primarySource": "https://www.wowhead.com",
    "generatedAt": "YYYY-MM-DD",
    "localeItemNames": "enUS"
  },
  "Death Knight": {
    "Blood": { ... },
    "Frost": { ... },
    "Unholy": { ... }
  },
  ...
}
```

Per spec object:

- `sourcePages`: array of Wowhead guide URLs you used (at least one).
- `warnings`: optional array of strings for unverified items.
- `omitWeaponOil`: boolean (true for Death Knight specs).
- For each category below, use the same structure:

Categories (keys):

| JSON key | UI label | Notes |
|----------|----------|--------|
| flask | Flask | List best + alternates (stat-specific flasks) |
| combatPotion | Combat Potion | DPS/tank combat pots for Midnight |
| healingPotion | Health Potion | Highest healing potion for current expansion |
| weaponOil | Weapon Buff | Skip for DK (`omitWeaponOil`) |
| augmentRune | Augment Rune | Current season augment rune |
| feast | Feast | Group feast items |
| personalFood | Personal Food | Solo food when not using feast |

Category object shape:

```json
"flask": {
  "best": [ { "id": 123, "name": "...", "wowheadUrl": "..." } ],
  "alternates": [ ... ],
  "noteEn": "One short line why this is best.",
  "noteNl": "Optioneel: korte Nederlandse regel."
}
```

- `best`: 1–2 items (primary recommendation).
- `alternates`: 0–4 items (valid alternatives).
- Order arrays by priority (best first).
