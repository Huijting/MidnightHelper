## Midnight Helper

Midnight Helper is an all-in-one utility addon for WoW Retail players who want a fast weekly overview across characters.

### Highlights

- Delves dashboard and Great Vault helper (Travel Assistant for cross-zone hops; TomTom optional for map arrows)
- Consumables tab per spec (Wowhead-backed, with guide search preview)
- Account snapshot with alt overview
- Compact Great Vault status per character:
  - World / Dungeons / Raids
- Subtle reset-day highlight for claimable vault rewards
- Profession helper tools
- SMC City Guide with waypoint support
- Optional TomTom integration
- English + Dutch localization

### Slash Commands

- `/mh` or `/midnight` - Toggle UI
- `/mh lang en` - English
- `/mh lang nl` - Dutch
- `/mh settings` - Settings popup
- `/mh debug` - Debug mode

### Notes

- Great Vault and alt snapshot values are based on the latest saved data for each character.
- For complete account coverage, log each character at least once after weekly reset.
