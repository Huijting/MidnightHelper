# Class quests: alle gebieden van een doel (26 nov 2026)

Rob (via Sparring): *"Overigens heeft Polestar wel in de gaten dat er meer gebieden zijn dan alleen maar dit, waarbij ik
deze [Kodo Horns] kan pakken."* Geen Polestar- of andere GPL-data gebruikt.

## Hoe het werkt
- `Modules/ForeverClassQuestAreas.lua` (GEGENEREERD, niet met de hand bewerken): `ns.FOREVER_CQ_AREAS[textKey] =
  { { m, x, y, n }, … }`, grootste gebied eerst.
- `ForeverClassQuests.lua` `NearestArea`: bij een "do"-stap met meer dan 1 gebied wijst de stap naar het gebied met de
  kortste reistijd (ForeverTravel); zonder positie het grootste. Kaartje en chat: "N areas, this one is nearest".
- Generator: `CQ_AREAS_generator_2026-11-26.py.txt` (draaien als scratch-script). Invoer `CQ_MOBS_2026-11-26.json`.

## Bronnen
- Welke npc bij welk doel: mh-research, 26 nov → `CQ_MOBS_2026-11-26.json` (261 doel-sleutels: 87 met npc's, 174
  overgeslagen met reden: praten, object, item gebruiken, dungeon, …). Elk npc-id is op naam gecontroleerd in de Wowhead
  Forever-tooltip (GEMETEN).
  Bronnen in dat bestand: ZY = Zygor Forever (Rob 22 nov: id's/plekken mogen over), WHF = Wowhead Forever,
  GS = GoldScout (wowgoldscout.com, door spelers waargenomen Forever-loot).
- Spawnpunten: Wowhead Forever-tooltip (`map.coords`), zone → uiMap via DB2 UiMapAssignment + UiMap (Type 3), Forever
  1.60.1.71139 (GEMETEN). Gebieden: punten binnen 7 kaart-% horen bij elkaar; gebieden van 1–2 punten vallen weg als er
  een groter gebied is.
