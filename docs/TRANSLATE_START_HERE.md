# Translation — start here

These are the strings a new user meets first: the tab bar, the main window, the Home
dashboard, and Settings. Translating just this list already makes Midnight Helper feel
native — the long reference guides can wait.

**248 strings.** You don't have to do them all. A single section is a real contribution.

## How to use this

1. Copy a block below.
2. Replace the English text between the quotes with your language. **Leave the KEY alone.**
3. Paste it into a [translation issue](https://github.com/Huijting/MidnightHelper/issues/new?template=translation.yml).

## Leave these exactly as they are

| You'll see | What it is | Rule |
|---|---|---|
| `%s`, `%d` | The game fills in a name or number | Keep it. You may move it in the sentence. |
| `%%` | A literal percent sign | Keep both characters. |
| `\|cffffffff` … `\|r` | Colour codes | Keep the pair around the same words. |
| `\|n` | A line break | Keep it where the layout needs it. |
| `{SPELL:12345}` | A spell name, filled in by the game | Never translate the number. |
| `->` in `Basics -> Dawncrests` | A menu path | Translate the words, keep the arrow. |

If a string won't fit or makes no sense out of context, say so in the issue — that's useful.
