# PoC: season_end as a Knowledge Object

Read-only proof of concept for RFC-001, run 2026-07-27. **Nothing was written into
the addon.** One article, one direction, one language, and a diff as the result.

Scripts and artefacts live in the session scratchpad under `poc/`; this file is the
report.

---

## Acceptance criterion, agreed before implementing

> The PoC fails if the Knowledge Object needs Codex-specific placement or
> rendering fields — `category`, `sort`, locale keys, tab ids, or WoW markup — in
> order to reproduce the existing article.

Checked mechanically at the end of the run against a forbidden-token list.

---

## 1. The Knowledge Object

`SEASON-001.md`. Front matter plus prose, no Lua, no markup.

```yaml
id: SEASON-001
title: "When a season ends"
topic: seasons
audience: beginner
season_proof: true          # contains no item level, no date, no season number
evidence_refs:
  - gear-at-a-rollover      # EVIDENCE_REGISTER.md, ADDON_RESEARCH
  - s2-item-levels          # EVIDENCE_REGISTER.md, COMMUNITY_REPORTED
search_terms: [season end, ends, ending, reset, rollover, roll over, new season,
               carry over, carryover, currency, deadline, expire, expires,
               last week, seizoen einde, afloopt, overgang]
deliberately_not_claimed:
  - "unclaimed track rewards are lost"     # they return at a vendor, dearer
  - "a hard rule for crest conversion"     # sources disagree; points at the game
points:
  - emphasis: "Your gear does not reset."
    text: "Everything you are wearing carries over at the item level it already has. ..."
  - emphasis: "The numbers move, not your progress."
    text: "Each season raises item levels, ..."
  # ... seven in total
```

**The prose was extracted from the existing article, not retyped.** Retyping 1487
characters would have measured my transcription rather than the architecture. What
is under test is whether the *structure* survives a round trip through an object
carrying no Codex field — so the text had to go in byte-identical.

Note `points`: each is an optional emphasis span plus its text. That shape came
out of the article itself. Two of the seven have an emphasis that does not end at
a sentence boundary ("Seasonal currencies usually do not survive a rollover
intact" runs straight into an em dash), so "bold the first sentence" would have
been the wrong abstraction.

## 2. The output mapping

`codex_mapping.py`. Everything in it is a fact about Midnight Helper, not about
the knowledge.

```python
PLACEMENT = {
    "SEASON-001": {
        "article_id": "season_end",
        "category": "start",
        "sort": 7,
        "key_stem": "SEASONEND",
    },
}

MARKUP = {
    "key_prefix": "CODEX_", "bullet": "• ",
    "emphasis_open": "|cffffffff", "emphasis_close": "|r",
    "point_separator": "|n",
}
```

Plus `render_body()`, `locale_keys()` and `registry_row()` — about forty lines.

## 3. Generated output

```lua
{ id = "season_end", category = "start",
  titleKey = "CODEX_SEASONEND_TITLE", bodyKey = "CODEX_SEASONEND_BODY",
  sort = 7, searchKeys = "season end ends ending reset ..." }

CODEX_SEASONEND_TITLE = "When a season ends"          -- 18 chars
CODEX_SEASONEND_BODY  = "• |cffffffffYour gear ..."   -- 1487 chars
```

## 4. The diff

| Field | Result |
|---|---|
| `id`, `category`, `titleKey`, `bodyKey`, `sort` | match |
| `CODEX_SEASONEND_TITLE` | **identical**, 18 chars |
| `CODEX_SEASONEND_BODY` | **identical**, 1487 chars |
| `searchKeys` | **differs** — see below |

The body regenerated byte-for-byte from structured points: seven bullets, the
emphasis spans, the separators, all of it.

The one difference:

```
repo:      ... last week seizoen einde afloopt reset overgang
generated: ... last week seizoen einde afloopt overgang
```

**The generator is not wrong here.** The hand-written `searchKeys` contains three
duplicated terms — `season`, `reset` and `over` each appear twice, 24 terms of
which 21 unique. The Knowledge Object holds a de-duplicated list, so the generated
string is one word shorter.

Matching is substring-based, so a repeated term changes nothing a user would
notice. The diff found a small redundancy in the original, which is precisely what
a diff against real content is for.

## 5. Verdict

**PASS.** The article reproduces from an object containing no placement and no
markup. The falsifier check found none of `category`, `sort`, `titleKey`,
`bodyKey`, `tabId`, `delvesSection`, `currencyId`, `|cff`, `|n`, `|r`, `CODEX_`
in the Knowledge Object.

## 6. What could not be generated without leaking upstream

Three things. All were solved inside the mapping, so none falsifies the model —
but each is a cost worth stating before scaling to 39 articles.

**Locale key names are not derivable.** `season_end` → `SEASONEND` works by
dropping the underscore, but `gear_tracks` → `CODEX_TRACKS_TITLE` and
`warband_bank` → `CODEX_WARBAND_TITLE` follow no rule at all. These were named by
hand over months. So `key_stem` must be stored per article: the mapping needs 39
entries, not one rule. That is bookkeeping, not architecture, but it is bookkeeping
that has to be right or the linter fails the build.

**`sort` is relative, not intrinsic.** 7 means "after `s2_terms` at 6". A knowledge
object cannot know it, and correctly does not — but it also means the mapping
entries are not independent of each other. Inserting an article renumbers its
neighbours.

**The other six languages are untouched.** By design: one language was the point.
Nothing here shows whether a Dutch, German, French, Spanish, Portuguese or Italian
body regenerates, and those are hand-written prose rather than translations of a
canonical source. This remains the expensive open question and the PoC deliberately
did not answer it.

## Two smaller observations

The emphasis structure is a genuine finding rather than a formatting detail — it
is the article's own rhetoric (a claim, then its support) made explicit. That is
the kind of thing a PDF or a website would want to style differently, and it is
now available to do so.

`deliberately_not_claimed` has no output in the Codex at all. It exists so that a
future writer cannot reintroduce "unclaimed rewards are lost" without stepping over
a line that says why not. Knowledge about what *not* to say has nowhere to live in
the current registry, and it survived the round trip only because nothing consumes
it yet.
