# Keybind-maps (v6 toegepast) — Frost Mage & Enhancement Shaman

Standaard: `docs/KEYBIND_STANDARD_v6.md`. Kit + spell-ID's: web-research (Icy Veins/Wowhead,
12.0.7). **Labels:** ✅ ID bevestigd · 🟡 waarschijnlijk · ⚠️ ID onbevestigd — **Rob/Cisca in-game
bevestigen** vóór het in `KeybindingData.lua` gaat (never-lie).

Ankers (beide specs, verplaatsen nooit): **E**=interrupt · **Q**=movement · **Z**=kleine def ·
**C**=grote def · **V**=dispel/CC · **F1**=grote cooldown · **Shift+E**=racial · **Ctrl+F1**=trinket ·
**Alt+C**=potion. Overflow = zelfde toets, volgende modifier (**Shift→Ctrl→Alt**).
