## Notes

1. **LFR wing rows (DERIVED which one Timear uses).** There are 3 LFGDungeons rows per Legion wing.
   - 1494/1610: the original LFR, with tank/healer counts and a player condition.
   - 1920/1916: 25 dps, minimum 1, flags 5139/8224. This is the same shape as the only BoD row (1950, "Victory or Death"), so I take these as the current legacy LFR rows.
   - 2835/2821: Random_ID 3084, probably Legion Remix.

   Gates of Hell differs between the rows:
   - deDE: 1494 "Die Tore der Hölle", 1920/2835 "Tore der Hölle".
   - frFR: 1494/1920 "Les portes de l’enfer", 2835 "Portes de l’enfer".
   - itIT: 1494/2835 "Cancelli dell'Inferno", 1920 "I cancelli dell'inferno".

   Light's Breach differs only in frFR: 2821 "Brèche de Lumière", the rest "La Brèche de Lumière".
2. **"Damned If You Don't" is a quest, not an achievement.** No achievement with that title was found in wago Achievement (search "Damned" only gave 63512 "Treasures of the Damned").
3. **The expansion names really are English in all 7 locales.** The control is that EXPANSION_NAME0 differs per locale (frFR/itIT/ruRU "World of Warcraft", es "World of Warcraft: Clásico", ptBR "Clássico") and `CANCEL` is translated.
4. **NOT FOUND (esMX)** only applies to rows that exist only on Wowhead: Nightbane, Damned If You Don't, A Titanic Problem, Kiku, Eppu, Portal to K'aresh. For these I searched wago Creature / JournalEncounterCreature / PlayerCondition / CriteriaTree / BroadcastText / AreaPOI. Empty results prove nothing.
